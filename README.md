# Godot game: Space Mercenary (WIP)
This is my second Godot game project.
It is a small 16-bit style shoot'em up game meant to prove my self and my own skills.

## Current features:
### Data driven game structure:
Almost every aspect of the game can be built thanks to a reusable set of scripts that makes possible the creation of key elements such as: projectiles, enemies, obstacles and bosses without the need of writing a separate script for different type of behaviors to lighten the level design workload.

### Enemies behavior:
A single script is used to design multiple enemies behaviors by selecting a preset and poking its settings. This makes enemies easy to implement.

### Bosses:
Bosses are highly customizable, unique boss battle sequences can be designed stage by stage within the inspector and no scripting is required, if any only animations should be hand made but with this highly customizable boss stage inspector you just have to drop the animation on the right field to behave as needed.

### Dialogue system:
This one is pretty basic as it should be on a 16-bit sytle game.
